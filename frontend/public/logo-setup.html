📋 Instructions to Set Up Your Fire Brigade Logo

Step 1: Save your logo image as "firelink-logo.png" in the public folder
Step 2: Create favicon sizes:
  • 16x16 pixels → favicon.ico
  • 32x32 pixels → favicon.ico
  • 192x192 pixels → logo192.png
  • 512x512 pixels → logo512.png
Step 3: Replace these files in the public folder:
  • favicon.ico
  • logo192.png
  • logo512.png
